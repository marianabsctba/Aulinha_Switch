Glossário técnico

O que cada comando faz

enable

Entra no modo privilegiado. É onde você pode visualizar e alterar configurações mais sensíveis. Em equipamento real, isso precisa ser protegido.

configure terminal

Entra no modo de configuração global. Daqui você muda comportamento do equipamento. Ou seja: é o modo “agora dá para quebrar bonito”.

hostname

Define o nome do switch. Ajuda na operação, troubleshooting e documentação. Equipamento sem nome em rede grande vira caça ao tesouro corporativo.

enable secret

Configura senha protegida para o modo privilegiado. É melhor que enable password, pois não deixa a senha em texto claro.

service password-encryption

Ofusca senhas simples no arquivo de configuração. Não é criptografia forte, mas evita exposição boba em print, backup ou show running-config.

banner motd

Exibe aviso legal no acesso ao equipamento. Ajuda em governança e controle de acesso: “não autorizado, não entra”. Simples e útil.

line console 0 e line vty 0 4

Configura acesso local via console e remoto via VTY/SSH/Telnet. Neste lab usamos senha e login para fins didáticos; em produção, prefira AAA/SSH.

vlan 10 e interface vlan 10

Cria uma VLAN e uma SVI para gerenciamento. Switch L2 não roteia entre redes, mas pode ter IP para ser administrado.

ip default-gateway

Define o gateway que o switch usa para responder fora da própria sub-rede de gerenciamento. Sem isso, acesso remoto de outra rede pode falhar.

interface range + switchport mode access

Coloca portas como acesso para endpoints. Porta access pertence a uma VLAN específica e não transporta múltiplas VLANs como trunk.

no shutdown

Ativa administrativamente a interface. Em muitos switches físicos as portas já vêm ativas, mas é comando essencial para entender estado administrativo.

copy running-config startup-config

Salva a configuração atual na memória de inicialização. Sem salvar, reiniciou e perdeu. A rede não perdoa romantismo operacional.
